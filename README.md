# 十日终焉：在线桌游

> 技术人员接手前先阅读：[`docs/technical-handoff.md`](docs/technical-handoff.md)。该文档记录当前单机剧情 RPG 的产品约束、两章玩法状态机、角色/语音/资产锁、测试、部署和后续章节开发流程。

非官方同人项目。目标是将《十日终焉》的正篇、人物番外、游戏规则、角色私密信息与失败分支，转换为可多人协作游玩的原著模式桌游。

## 原文与视觉规则

原文基线已随仓库保存于：

[`reference/canon/十日终焉 1--1496 完结 杀虫队队员.txt`](reference/canon/%E5%8D%81%E6%97%A5%E7%BB%88%E7%84%89%201--1496%20%E5%AE%8C%E7%BB%93%20%E6%9D%80%E8%99%AB%E9%98%9F%E9%98%9F%E5%91%98.txt)

所有工作人员克隆仓库后即可生成正史清单，无需访问原开发电脑：

```powershell
npm.cmd run canon:manifest
```

只有在审计另一份原文版本时，才用环境变量覆盖默认路径：

```powershell
$env:CANON_SOURCE = "C:\\path\\to\\十日终焉.txt"
npm.cmd run canon:manifest
```

视觉出处与允许用途位于 `content/official-visual-reference.json`：

1. 实体书与官方出版物：标题、封面与卷册语汇。
2. 腾讯视频与番茄动漫官方动画物料：人物、生肖、终焉之地与回响表现。
3. 腾讯视频与柠萌影视官方剧集物料：建筑、服化道与写实材质；不混入默认动画桌游皮肤。
