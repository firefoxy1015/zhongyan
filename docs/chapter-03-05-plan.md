# 第三至第五章制作计划

## 1. 正史范围

| 游戏章节 | 原著章节 | 原文行 | 章节终点 |
|---|---:|---:|---|
| 第三章《七黑剑》 | 22-29 | 3001-4142 | 四人离开广场，遇见人鼠 |
| 第四章《仓库寻道》 | 30-35 | 4143-4986 | 形成“先探规则、再赌命”的队伍战术 |
| 第五章《地牛》 | 36-48 | 4987-6744 | 黑熊游戏结算，拒绝可疑女子并带走熊臂 |

正文身份使用“原文文件哈希 + 章节号 + 行范围”，不只使用章节号。

## 2. 连续性冻结

- 第三章开场：九人存活；甜甜右掌伤；韩一墨肩部重伤且失血；齐夏持有四颗“道”。
- 第三章固定结果：韩一墨被七黑剑贯穿死亡；一颗“道”用于取得鱼钩与鱼线；一颗交给李尚武；齐夏、乔家劲、甜甜、林檎组成探索队。
- 第四章固定结果：人鼠死亡；朱雀首次出现；甜甜本名“张丽娟”被说出；队伍共有五颗“道”；杀人夺道试探被全员拒绝。
- 第五章固定结果：黄队一人死亡、九人生还；绿队十人生还；乔家劲承担铁板正面冲击；张山杀死另一场黑熊；地牛发放每人十九颗“道”；齐夏归还小眼镜一袋，保留队伍净额九十六颗“道”。
- 角色旧版立绘和音色继续锁定；新角色使用独立版本号，不覆盖旧资产。

## 3. 玩法闭环

### 第三章

1. 观察便利店的污秽、收银台、员工门与锅。
2. 选择用一颗“道”结清鱼钩和鱼线；错误选择说明具体危险。
3. 完成七黑剑证据板：天花板完整、剑重约一百五十斤、铭文位于死者视线另一侧、韩一墨却说出剑名。
4. 完成分队与“道”的分配，保留固定成员和数量。
5. 在广场记录钟声与“招灾回响”，进入下一章。

### 第四章

1. 由甜甜执行第一次五分钟搜索，按原著推倒货架、关灯、检查罐头并失败。
2. 从规则措辞与裁判行为中闭合三条证据：规则强调“现在”、人鼠看不到房间却知道失败、关门后房间中没有“道”。
3. 选择赌命并在开局瞬间从人鼠口袋取得“道”。
4. 朱雀执行规则；玩家可要求放过人鼠，但不能改写正史结果。
5. 对队友提出“杀人夺道”试探；三人必须拒绝，随后冻结真正战术。

### 第五章

1. 支付四颗“道”，接受随机分队。
2. 判断黑熊不能靠装死规避，并选择中央圆铁板作为唯一场地工具。
3. 组装“老鹰捉小鸡”阵型：乔家劲抵板、齐夏从后方指向、其余人纵列跟随。
4. 用鞋击打黑熊背部与鼻部，引开黑熊并救回老吕；交易两人的通关奖励。
5. 承受助跑冲击与最后二十秒，保留小眼镜主动引走黑熊的正史行动。
6. 完成结算、张山冲突、逃离笔记与可疑女子判断。

## 4. 代码结构

```text
app/lib/story-chapters/types.ts       # 第3-5章共享类型
app/lib/story-chapters/canon.ts       # 正史场景、题目、对白和行号
app/lib/story-chapters/engine.ts      # 纯 reducer、错误诊断、死亡和通关
app/lib/story-chapters/save.ts        # v3存档、v2迁移、章节门禁
app/lib/story-chapters/assets.ts      # 图片和音频锁定清单
app/lib/story-chapters/audio.ts       # 本地BGM/SFX/对白播放
app/chapter/[3|4|5]/page.tsx          # 三个路由入口
app/chapter/[3|4|5]/StoryChapterGame  # 统一桌游式页面
```

引擎先于 UI 完成。所有错误返回字段级说明；危险错误会进入死亡状态，并明确返回检查点。

## 5. 视听与动画

- 第三章：便利店全景、店员立绘、七黑剑/钟声/分队动画。
- 第四章：仓库全景、人鼠与朱雀立绘、关灯搜索/口袋取道/朱雀降临动画。
- 第五章：地下场地、地牛与张山立绘、铁门开启/黑熊冲撞/铁板转向/结算动画。
- BGM 与 SFX 为仓库内静态文件；第一次用户手势启动，语音播放时压低 BGM。
- 固定对白一人一音色、一句一文件；运行时不生成。若文件缺失，播放器显示缺失，不调用浏览器 TTS。
- `prefers-reduced-motion` 只缩短动画，不跳过状态转换。

## 6. 验收

1. 正史测试锁定章节、行号、人物生死、伤情、道具和“道”数量。
2. 引擎测试分别跑通三章成功路线、所有字段错误和死亡检查点。
3. 存档测试覆盖 v2 -> v3 迁移、章节 3-5 门禁和损坏档案。
4. 资产测试校验所有文件、哈希、尺寸和版本。
5. SSR 测试检查三条路由、首页调试直达和不泄露答案。
6. 手工验收桌面与 390x844：无横向滚动、立绘不裁头、记录区可滚动、按钮可达、首次点击有声。
